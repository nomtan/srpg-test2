# ジョブ仕様

## 転職・取得ルール

- ジョブは下位・上位・最上位の3段階とする。
- 各下位ジョブを一定レベルまで育成すると、対応する上位ジョブ2種を取得できる。
- 各上位ジョブを一定レベルまで育成すると、対応する最上位ジョブ2種が取得候補になる。
- 最上位の通常取得枠は、対応する上位ジョブ1種の必要レベル到達のみで取得できる。
- 最上位の特殊取得枠は、同じ上位ジョブ1種の必要レベル到達に加え、別途定める特殊条件を満たすと取得できる。
- **上位ジョブ2種の育成・取得を要求する旧条件は廃止する。** 特殊条件にも他の上位ジョブの育成・取得は要求しない。
- 分岐は排他的ではない。同一キャラクターが両方の分岐先を取得できる。ジョブの取得と現在のジョブへの転職は区別する。
- 必要レベルは下位→上位、上位→最上位それぞれ未確定。本仕様書では具体的な数値を設定しない。
- 各上位ジョブにつき最上位の片方を特殊取得枠とする。特殊条件の内容（イベント・契約・アイテムなど）は今後決定する。
- 特殊条件が未定義のジョブは、必要レベルだけで自動取得させない。実装時には未解禁として扱う。

下位8種・上位16種・最上位32種。以下は系統ごとのツリー案で、追加ジョブの名称・役割、通常枠・特殊枠の配置は設計案。
必要レベルと特殊条件の具体的内容は未確定。特殊枠は通常枠の取得を前提とせず、異なる戦術・固有能力を持つ分岐として設計する。
既存の最上位「魔法剣士」は剣術師系統の上位へ移し、それ以外の既存最上位11種は最上位に維持する。
数値補正・スキル・装備適性は別途調整する。

## 実装時の条件表現

- 上位ジョブ：親となる下位ジョブ1種と必要レベルを保持する。
- 最上位ジョブ：親となる上位ジョブ1種、必要レベル、取得枠（通常／特殊）を保持する。
- 特殊枠には追加条件を保持し、親ジョブのレベル条件と追加条件の両方を評価する。
- 特殊条件の未定義と、追加条件不要の通常枠を区別する。
- 取得判定はキャラクターが保持する対象ジョブの育成レベルを参照する。現在装備しているジョブだけで判定しない。
- 旧データにある複数上位ジョブの組み合わせ条件は、新ツリーの親ジョブ1種の条件へ置き換える。
- 既存ジョブIDは可能な限り維持する。魔法剣士はIDを維持しつつ階級・親ジョブを変更する。追加ジョブのIDは実装時に確定する。
- 既取得ジョブを持つセーブデータの移行方針は別途決定する。仕様変更だけを理由に取得済みジョブを自動削除しない。
