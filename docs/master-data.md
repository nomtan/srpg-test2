# Godotのマスターデータ

ゲーム起動時に `data/admin/jobs`、`skills`、`equipment` のJSONを読み込みます。有効なレコードが同じIDの内蔵定義を上書きします。ファイルの欠損や無効な値、習得スキル・転職元の参照切れがある場合は、警告を記録して利用可能な内蔵定義を使います。

## ジョブ仕様と現行データの差分（GODOT-007）

各セルの最上位ジョブは「通常枠 / 特殊枠」の順です。分岐名は [ジョブ仕様](job.md) の設計案です。

| 下位 | 上位 → 最上位の分岐案 | 現行データと移行状況 |
| --- | --- | --- |
| 格闘師 | モンク → 拳聖 / 武神、闘士 → チャンピオン / ベルセルク | モンクは登録済み。拳聖と武神は新規解放保留。闘士系は未登録 |
| 剣術師 | 聖騎士 → パラディン / 剣聖、魔法剣士 → ルーンナイト / 精霊剣士 | 魔法剣士を上位へ変更。パラディン・剣聖・魔法剣士は新規解放保留 |
| 槍術師 | 竜騎士 → ドラグーン / 竜槍騎士、槍闘士 → ランスマスター / 槍聖 | 竜騎士は登録済み。槍聖は新規解放保留。槍闘士は未登録 |
| 斧術師 | 重騎士 → フォートレスナイト / イージスナイト、斧戦士 → ウォーロード / デストロイヤー | 重騎士は登録済み。フォートレスナイトは新規解放保留。斧戦士系は未登録 |
| 弓術師 | スナイパー → ホークアイ / ガンスリンガー、レンジャー → ハンター / ビーストマスター | スナイパーは登録済み。ガンスリンガーは新規解放保留。レンジャー系は未登録 |
| 双剣師 | 忍者 → 影忍 / アサシン、剣舞士 → ブレイドダンサー / 幻影剣士 | 忍者は登録済み。アサシンは新規解放保留。剣舞士系は未登録 |
| 治癒師 | プリースト → ハイプリースト / 聖者、薬師 → アルケミスト / 学者 | プリーストは登録済み。アルケミストと学者は新規解放保留。薬師は未登録 |
| 魔術師 | ソーサラー → アークメイジ / 賢者、呪術師 → ウォーロック / ネクロマンサー | ソーサラーは登録済み。ネクロマンサーは新規解放保留。呪術師は未登録 |

最上位の新規解放には上位ジョブ1種の必要レベルを使います。旧来の上位2種要件を削除した12レコードは `unlockPending: true` とし、既に取得しているジョブID・レベル・経験値はそのまま使用します。既存上位8件のLv 5条件は移行期間中の現行値です。

## パッシブ能力補正とリアクション

`type: "passive"` と `activationMode: "equipped"` を指定します。常時補正は `effects` 配列に以下の形式で登録します。

```json
{ "type": "stat_bonus", "stat": "max_ap", "mode": "percent", "value": 20 }
```

`mode` は `flat` または `percent`（20は20%）です。各能力は固定値を合算し、その後に割合の合計を適用して四捨五入します。基礎6能力はジョブと装備の補正後、派生能力と属性耐性は各計算と装備補正の後に適用します。条件付きの常時補正は読み込み時に警告を記録して除外します。

リアクションは `triggers` の `on_attacked` に登録します。1回の被攻撃に対して、パッシブごとに最初の該当条件で抽選します。反撃は通常攻撃の射程・命中・クリティカル判定を使い、`powerMultiplier` でダメージを調整します。自己回復量は `round((power + floor(MND × 1.5)) × powerMultiplier)` です。`power` の既定値は0、倍率の既定値は1です。

## スキルアイコン

管理画面でPNGまたはWebPを登録すると、スキルJSONの `iconPath` と `admin/public/skill-icons/` の画像が更新されます。同じチェックアウトでGodotを起動すると画像を共有します。管理画面とGodotを別の作業フォルダで開いている場合は、該当するJSONと画像の両方をGodot側へ同期し、ゲームを再起動してください。

画像のないスキルには共通の代替アイコンが表示されます。Godotからエクスポートする場合は `data/admin` のJSONを非リソースファイルとして含め、登録したPNG・WebPと代替SVGをリソースに含めます。
