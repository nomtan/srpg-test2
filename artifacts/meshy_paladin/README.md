# Meshy パラディンの歩行リグ

- `blue_plume_paladin_walk.blend`: リグと歩行アニメーションを付けたモデル。
- `blue_plume_paladin_before_rig.blend`: リギング前のバックアップ。
- `rig_paladin.py`: このモデルの形状に合わせた作成・ウェイト・歩行生成コード。
- `validation.json`: 全フレームの接地、ウェイト、ループ接続の検証結果。

Blenderで完成ファイルを開き、タイムラインの再生ボタンで歩行を確認できます。
再生範囲は1〜32フレーム、24fps（1周約1.33秒）。33フレーム目は1フレーム目と一致する補間用のキーです。
アクション名は `Walk_InPlace`、アーマチュア名は `Paladin_Rig` です。

24本のFKボーンに、腕・脚・足先・頭・胴体・前垂れのウェイトを設定しています。
ルートはその場に留まり、キャラクターの前方向はBlenderの-Yです。
元のメッシュ、UV、3種類の埋め込みテクスチャを保持しています。

見た目を確認しやすいようにビューポートのオーバーレイをオフにしています。
ボーンを編集するときはオーバーレイをオンにし、`Paladin_Rig` を選択してポーズモードに切り替えてください。
リグはFK式で、IKコントローラー、指の個別ボーン、物理クロスは追加していません。

元ファイル（Downloads内）には上書きしていません。
