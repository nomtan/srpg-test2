# Hair test fixtures

`901/model.glb` and `902/model.glb` are small, static socket test meshes, not production hairstyles. They are generated by `tools/asset_gen/character_pipeline/make_hair_test_fixtures.py` and used by `verify_modular_parts.gd` to test Hair swapping with multiple Body/Face combinations. Real Hair assets should come from immutable `assets/characters/tripo/hair/<id>/model.glb` and pass the normalization and validation flow documented in `docs/character/tripo-character-pipeline.md`.
