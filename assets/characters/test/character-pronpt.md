The **canvas is 16 × 16 pixels**, but the character must retain the compact visual scale and pixel density of the attached reference.

Do NOT automatically enlarge the character to fill the entire canvas.

Do NOT create a high-detail 16-pixel-tall illustration.

Preserve:

- reference pixel density
- reference proportions
- reference detail level
- reference weapon scale
- reference head size

Leave transparent padding around the silhouette.

As a general guideline, the visible character may occupy approximately:

**8–12 pixels in height**

depending on:

- hairstyle
- helmet
- hat
- weapon
- shield
- cape
- accessories

However:

**the attached reference determines the final apparent character scale.**

If the reference sprite appears smaller, keep it smaller.

Do not increase character size simply because empty canvas space is available.

# Pixel-Art Style

Match the attached reference as closely as possible.

Use authentic small-scale hand-crafted pixel art.

The character should look as though every pixel was intentionally placed.

Use:

- crisp pixel clusters
- deliberate 1-pixel details
- controlled jagged contours
- compact shadow groups
- stepped pixel shading
- selective highlight pixels
- readable material separation
- compact facial features
- strong silhouette design

Do NOT create a high-resolution illustration and reduce its resolution afterward.

Do NOT use:

- automatic pixelation
- mosaic filters
- downscaled digital painting
- blurred pixel edges

The sprite must be designed directly as **true low-resolution pixel art**.

# Rendering and Shading

Match the shading complexity of the attached character.

Because this is a **16 × 16 px gameplay sprite**, every pixel must contribute to readability.

Use compact shading.

As a general guideline, use approximately:

**3–5 major shades per material**

where appropriate.

Avoid unnecessary intermediate colors.

### Metal

Use:

- sharp small highlights
- medium base tones
- compact dark shadows
- occasional bright specular pixels

### Cloth

Use:

- stepped shading
- compact folds
- restrained highlights

### Leather

Use:

- warm intermediate tones
- dark edge separation

### Hair

Render hair as intentional pixel clusters.

Do not draw individual realistic hair strands.

Match the reference's hair-detail density.

### Skin

Use a very compact palette.

Facial shading should remain minimal.

### Weapons

Weapons must remain readable even at the 16 × 16 gameplay scale.

Slight exaggeration of weapon size is acceptable when consistent with the attached reference.
